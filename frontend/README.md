# WiseMann Frontend

An attractive, professional, and classy React-based frontend for the WiseMann supermarket inventory management system.

## 🚀 Features

### Pages Implemented
- **Dashboard** - Overview of store status with KPIs, alerts, and priority actions
- **Purchase Advisor** - AI-powered purchase recommendations with budget constraints
- **Inventory** - Product inventory tracking with search, filters, and risk assessment
- **Demand Forecast** - 7, 14, and 30-day demand predictions with confidence levels
- **Suppliers** - Supplier comparison by price, lead time, and reliability
- **What-if Analysis** - Scenario simulation for budget and demand changes
- **AI Store Manager** - Conversational AI assistant for inventory queries
- **Settings** - Account and notification preferences

### Design System
- **Premium Black & White** aesthetic with pure minimalism
- **Semantic colors**: Green (success), Amber (warning), Red (danger)
- **AI Purple** (#7C3AED) for AI-specific features
- **Professional typography** with clear hierarchy
- **Smooth animations** and transitions (150-250ms)
- **Responsive design** for desktop and mobile

## 🛠️ Tech Stack

- React 18 + TypeScript
- Vite 8 (Build tool)
- Tailwind CSS 4
- React Router DOM 6
- Zustand (State management)
- Axios (HTTP client)
- Lucide React (Icons)

## 📦 Installation & Setup

```bash
npm install
npm run dev      # Start dev server
npm run build    # Build for production
npm run preview  # Preview production build
```

## 🌐 Development Server

The dev server runs on **http://localhost:5173/**
